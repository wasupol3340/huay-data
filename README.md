# huay-data

ผลหวยที่ยืนยันแล้ว สำหรับหน้าเว็บสมุดสถิติหวย อัปเดตอัตโนมัติทุกคืนโดยทีม AI

- `results.json` ผลรางวัลทุกงวด: `th` หวยไทย, `vn` หวยฮานอย (XSMB), `la` หวยลาวพัฒนา, `pb` Powerball, `mm` Mega Millions
- `journal.json` บันทึกหลังหวยออกแต่ละงวด ว่าทายอะไร ออกอะไร ถูกหรือไม่

ผลที่ใช้ขึ้นเงินได้ต้องดูจากประกาศทางการเท่านั้น
